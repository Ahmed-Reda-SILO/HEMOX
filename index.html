App-Ready Calibration Parameters

The tables below define the exact equations and A/B/C meanings used by the Android Calibration Model Setup.
Symbols: R = optical ratio-of-ratios; SpO₂cal = calibrated SpO₂ output (%); HRvalid = uncalibrated HEMOX validated HR (bpm); HRcal = calibrated HR output (bpm). Coefficients shown in the live cards are Android-domain parameters, not the intermediate output-transfer coefficients.

SpO₂ parameter definitions

ModelAndroid equationParameter meaning
M0 · No correctionSpO₂cal = 104 − 17RA = B = C = 0
M1 · Offset-onlySpO₂cal = 104 − 17R + AA = C₀, the percentage-point offset; B = C = 0
M2 · Full linearSpO₂cal = A + BRA = intercept (%); B = slope with respect to R; C = 0
M3 · QuadraticSpO₂cal = A + BR + CR²A = intercept (%); B = linear R coefficient; C = quadratic R² coefficient

Quality-valid fused distributions

Descriptive Gaussian overlays and quality statistics for fused HR and SpO₂.
Final fused windows are reconstructed from WINDOWS when available. Only finite values with fused SQI ≥ 0.55 and confidence not Low are retained; unavailable readings are excluded. FUSED_TRENDS is used only as the fallback source.

Research decision

Per-run screening decision with supporting pre-calibration channel values.
Decision boundaries: FAIL if either channel SpO₂ < 90%; PASS if both are ≥ 95% and |ΔSpO₂| ≤ 3%; otherwise REPEAT AFTER 1 HOUR. Missing either final SpO₂ produces REPEAT MEASUREMENT. Calibration never changes the decision.
